# مرجع الفيديوهات — تعليمات Claude

هذا المشروع **مرجع حيّ لذوق المستخدم في الفيديو**: شكل الفيديو، الكابشن، الانميشن، المونتاج.
المستخدم يعطيك مقاطع ريلز يعجبه أسلوبها → تحللها → تعيد صنع نفس الأسلوب → تتعلم من ملاحظاته → يتطور الملف مع الوقت.

> القاعدة الذهبية: **اقرأ `taste/profile.md` قبل أي عمل**، وحدّثه بعد أي ملاحظة من المستخدم.

## الهيكل

| المسار | الغرض |
|---|---|
| `taste/profile.md` | ملف الذوق — الحقيقة الحالية عن ما يحبه/يكرهه المستخدم. يُقرأ أولاً دائماً |
| `taste/feedback-log.md` | سجل ملاحظات المستخدم بالتاريخ (الخام، قبل تلخيصها في profile) |
| `references/<slug>/` | تحليل كل مقطع مرجعي: `analysis.json` + `breakdown.md` + لقطات |
| `references/_TEMPLATE/breakdown.md` | قالب التحليل |
| `styles/caption-presets.json` | أنماط الكابشن الجاهزة (تُستخدم مع `tools/captions.py`) |
| `styles/editing-recipes.md` | وصفات المونتاج والانتقالات والإيقاع (أوامر ffmpeg) |
| `styles/animation-library.md` | مكتبة حركات الكابشن والنصوص (وسوم ASS) |
| `inbox/` | المستخدم يضع المقاطع هنا (غير مرفوعة لـ git) |
| `projects/<name>/` | فيديوهات المستخدم الجديدة: خطة + كابشن + أوامر الرندر |
| `outputs/` | الفيديوهات النهائية (غير مرفوعة لـ git) |

## سير العمل

### 1) المستخدم يعطيك مقطع مرجعي
1. شغّل: `python3 tools/analyze.py inbox/<file> --slug <اسم-قصير>`
   أو من رابط مباشرة: `python3 tools/analyze.py --url "<رابط>" --slug <اسم-قصير>` (ينزّل إلى inbox/ بـ yt-dlp)
   أضف `--transcribe --language ar` لتفريغ الكلام → `references/<slug>/words.json` جاهز لـ `captions.py --words`.
   يُخرج: المدة، الأبعاد، fps، نقاط القطع (cuts)، متوسط طول اللقطة، الإيقاع، مستوى الصوت (LUFS)،
   و**لوحتين صور**: `contact_shots.jpg` (لقطة لكل مشهد) و `contact_timeline.jpg` (12 لقطة موزعة).
2. **افتح اللوحتين بأداة Read وانظر إليها فعلاً.** استخرج بصرياً: مكان الكابشن، الخط (سميك/رفيع)،
   الألوان، التحديد/الظل/الصندوق، عدد الكلمات على الشاشة، الإيموجي، الزوم، الفلاتر، الـ B-roll.
3. إذا أمكن، استخرج نص الكلام مع توقيت كل كلمة (انظر «التفريغ النصي» أدناه).
4. املأ `references/<slug>/breakdown.md` — افصل بين: **مقاس** (من الأداة) / **ملاحظ** (من الصور) / **تخمين**.
5. إذا ظهر نمط كابشن جديد → أضف preset في `styles/caption-presets.json`.
6. أضف سطراً في جدول المراجع في `taste/profile.md`، وحدّث الأنماط المتكررة إن تكرر شيء عبر ٣ مراجع أو أكثر.

### 2) المستخدم يريد فيديو بنفس الأسلوب
1. اقرأ `taste/profile.md` + breakdown المرجع المطلوب.
2. أنشئ `projects/<name>/plan.md`: اللقطات، الكابشن preset، الانتقالات، الموسيقى/الإيقاع.
3. كابشن: `python3 tools/captions.py --words words.json --preset <name> --out projects/<name>/captions.ass`
4. رندر: `ffmpeg -i input.mp4 -vf "ass=projects/<name>/captions.ass" -c:a copy outputs/<name>.mp4`
5. **تحقق قبل التسليم**: استخرج 3–4 لقطات من الناتج وافتحها بـ Read. تأكد أن العربي متصل وبالترتيب الصحيح،
   والكابشن داخل المنطقة الآمنة (ليس تحت أزرار الريلز السفلية ~ آخر 20% ولا الجانب الأيمن).
6. اعرض النتيجة واسأل سؤالاً محدداً واحداً عن الذوق (مثلاً: "الكلمة المميزة بالأصفر أو الأخضر؟").

### 3) المستخدم يعطي ملاحظة
- سجّلها حرفياً في `taste/feedback-log.md` (التاريخ + المرجع/المشروع + الملاحظة).
- ترجمها لقاعدة في `taste/profile.md` مع درجة ثقة: `مؤكد` (قالها صراحة أو تكررت) / `مرجّح` (مرة واحدة) / `تخمين`.
- إذا تعارضت ملاحظة جديدة مع قاعدة قديمة: الجديدة تغلب، واكتب التغيير في قسم «تطور الذوق».
- كل ٥ ملاحظات تقريباً: راجع profile ولخّصه، احذف المكرر.

## التفريغ النصي (توقيت الكلمات)
- **على جهاز المستخدم:** `analyze.py --transcribe` (Whisper محلي، مع توقيت كل كلمة). التركيب: `pip install -r requirements.txt`
  (~5 جيجا بسبب torch + النموذج أول مرة). `--whisper-model turbo` أو `large` أدق للعربي من `small` الافتراضي.
- **في السحابة:** الشبكة تحجب YouTube و Instagram وسيرفر نماذج Whisper (`openaipublic.azureedge.net`) و huggingface،
  فلا `--url` ولا `--transcribe` يشتغلان هناك إلا إذا سمح المستخدم بهذه المواقع في إعدادات الشبكة.
- البدائل: (أ) المستخدم يعطي ملف SRT/نص — `captions.py --srt`. (ب) أداة ElevenLabs `creative_transcribe_audio`
  إذا كانت متصلة — **تستهلك رصيد المستخدم، اسأله أولاً**. (ج) `--text` مع `--start/--end` لتوزيع الكلمات بالتساوي (تقريبي).
- صيغة `words.json`: `[{"text": "كلمة", "start": 0.00, "end": 0.42}, ...]`

## قواعد
- لا تخترع ما لم تره: إن لم تكن متأكداً من الخط أو اللون، اكتب "تخمين".
- انسخ **الأسلوب** لا المحتوى: لا تعِد رفع فيديو شخص آخر ولا تنسخ شعاره/علامته المائية.
- الملفات الثقيلة (mp4/mov/wav) لا تُرفع لـ git — فقط التحليلات والصور المصغرة والإعدادات.
- اكتب للمستخدم بالعربي.
