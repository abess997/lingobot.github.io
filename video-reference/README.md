# 🎬 مرجع الفيديوهات

مشروع يتعلّم ذوقك في الفيديو: **الشكل، الكابشن، الانميشن، المونتاج**.
تعطيني مقاطع ريلز تعجبك ← أحللها ← أسوي لك نفس الأسلوب ← تعطيني رأيك ← الملف يتطور مع الوقت.

## كيف تستخدمه

**١. أعطني مقطع يعجبك**
ارفع الفيديو (أو ضعه في `inbox/`) وقل لي **وش اللي عجبك فيه** — الكابشن؟ القطعات السريعة؟ الألوان؟
> مثال: «هذا المقطع، عجبني الكابشن الأصفر اللي يكبر مع كل كلمة»

**٢. أحلله**
أطلع لك: المدة، سرعة القطع، طول كل لقطة، مستوى الصوت، ولوحة صور من المقطع أقرأ منها شكل الكابشن والألوان.
يُحفظ التحليل في `references/<الاسم>/`.

**٣. أسوي لك نفسه**
أعطني فيديوك (والنص إن وجد) وأطبق عليه نفس الأسلوب.

**٤. قل رأيك**
«الخط كبير زيادة»، «أبي القطع أسرع»، «ما أحب الصندوق الأسود»… كل ملاحظة تنحفظ في `taste/` وأطبقها في المرات الجاية.

## الملفات
```
taste/profile.md          ← ذوقك (يتحدث مع كل ملاحظة)
taste/feedback-log.md     ← كل ملاحظاتك بالتاريخ
references/               ← تحليل كل مقطع مرجعي
styles/caption-presets.json  ← أنماط الكابشن الجاهزة
styles/editing-recipes.md    ← وصفات المونتاج
styles/animation-library.md  ← حركات النص
tools/analyze.py          ← أداة التحليل
tools/captions.py         ← مولّد الكابشن المتحرك
inbox/  outputs/          ← الفيديوهات (ما ترتفع على GitHub)
```

## أنماط الكابشن الحالية
| النمط | الوصف |
|---|---|
| `bold-pop` | أبيض سميك، الكلمة الحالية صفراء وتكبر |
| `single-word` | كلمة وحدة كبيرة بالنص مع حركة pop |
| `clean-box` | نص على صندوق أسود، هادئ |
| `green-karaoke` | سطر كامل، الكلمة الحالية خضراء |

كلها تدعم العربي (تم اختبار اتصال الحروف وترتيب الكلمات).

## ملاحظات
- الفيديوهات نفسها ما تنحفظ على GitHub (حجمها كبير) — فقط التحليلات والصور المصغرة. لو انتهت الجلسة، ارفع الفيديو مرة ثانية.
- التفريغ النصي التلقائي (تحويل الكلام لنص بتوقيت كل كلمة) غير متاح حالياً في هذه البيئة؛ أعطني ملف SRT أو النص، أو أستخدم ElevenLabs بعد موافقتك (يستهلك رصيد).
