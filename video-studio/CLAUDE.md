# Video Studio — مشروع إنتاج الفيديو والتصميم

هذا مجلد العمل الشخصي لإدارة إنتاج الفيديوهات والتصاميم باستخدام أداة **OpenMontage**
(موجودة في `OpenMontage/` كـ git submodule).

## اللغة
- تواصل مع المستخدم بالعربية (لهجة خليجية بسيطة مقبولة)، والمصطلحات التقنية تبقى بالإنجليزية.
- الملفات الإبداعية (سكربتات، كابشن) بلغة الفيديو المطلوبة — اسأل إذا مو واضح.

## قبل أي طلب إنتاج فيديو (إلزامي)
1. اقرأ `01-brand/brand-kit.md` — هوية المستخدم (ألوان، خطوط، نبرة صوت).
2. إذا فيه مرجع فيديو/تصميم، راجع `02-references/` أولاً.
3. افتح/أنشئ مجلد المشروع في `03-projects/` من القالب `03-projects/_template/`.
4. بعدها اشتغل من داخل `OpenMontage/` والتزم بـ `OpenMontage/AGENT_GUIDE.md` حرفياً
   (Rule Zero: كل إنتاج يمر عبر pipeline، اقرأ director skill لكل مرحلة، preflight قبل التكلفة).
5. أعلن المزوّد/الموديل/التكلفة التقديرية **قبل** أي استدعاء مدفوع، وانتظر موافقة المستخدم.

## خريطة المجلدات
| المجلد | الغرض |
|---|---|
| `01-brand/` | الهوية البصرية + ملف style جاهز لـ OpenMontage |
| `02-references/videos/` | سجل فيديوهات ملهمة + تحليلها |
| `02-references/designs/` | سجل تصاميم ملهمة (moodboard نصي) |
| `02-references/prompts/` | مكتبة برومبتات مجرّبة وناجحة |
| `03-projects/` | مشروع لكل فيديو: brief → script → shot list → تسليم |
| `04-assets/` | شعارات، خطوط، موسيقى، مؤثرات، لقطات، صور (مملوكة أو مرخّصة فقط) |
| `05-workflow/` | قوائم التحقق، تتبع التكاليف، تقويم المحتوى، دليل المفاتيح |
| `06-claude-ai-project/` | تعليمات جاهزة لمشروع Claude.ai (Projects) |

## قواعد ثابتة
- بعد كل مشروع: حدّث `05-workflow/cost-tracker.md` و `03-projects/<name>/delivery.md`.
- أي برومبت نجح بشكل ممتاز → أضفه إلى `02-references/prompts/prompt-library.md`.
- لا تضع مفاتيح API في أي ملف داخل هذا المجلد؛ مكانها `OpenMontage/.env` فقط (مستثنى من git).
- لا تستخدم أصول لها حقوق (شعارات/موسيقى/لقطات) بدون ترخيص مسجّل في `04-assets/LICENSES.md`.
- مخرجات OpenMontage الخام تبقى في `OpenMontage/projects/` (مستثناة من git)؛ الفيديو النهائي
  ارفعه لمكان تخزين خارجي وسجّل الرابط في `delivery.md` (ملفات الفيديو كبيرة على git).

## أوامر سريعة (slash commands)
- `/new-video` — يبدأ مشروع فيديو جديد من القالب.
- `/analyze-reference` — يحلل فيديو مرجعي ويسجّله.
- `/brand-check` — يراجع مخرج مقابل هوية البراند.
- `/wrap-project` — يقفل المشروع ويحدّث السجلات.
