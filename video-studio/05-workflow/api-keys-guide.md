# دليل مفاتيح API

المكان الوحيد للمفاتيح: `OpenMontage/.env` (مستثنى من git — لا تنسخه لأي مكان ثاني).

## بدون أي مفتاح تشتغل
Remotion · HyperFrames · FFmpeg · تفريغ صوتي محلي · تحليل فيديو/مشاهد · Piper TTS (يحتاج تحميل نموذج صوت).

## الأولوية المقترحة (ابدأ بالأقل)
| الأولوية | المفتاح | يفتح لك |
|---|---|---|
| 1 | `PEXELS_API_KEY`, `PIXABAY_API_KEY` (مجاني) | لقطات وصور وموسيقى مجانية |
| 2 | `ELEVENLABS_API_KEY` أو `GOOGLE_API_KEY` | تعليق صوتي عالي الجودة (يدعم العربي) |
| 3 | `FAL_KEY` | بوابة واحدة لموديلات صور وفيديو كثيرة |
| 4 | `OPENAI_API_KEY` | صور + TTS |
| 5 | `RUNWAY_API_KEY` / `KLING_API_KEY` / غيرها | توليد فيديو متقدم |

القائمة الكاملة والأسعار: `OpenMontage/docs/PROVIDERS.md` و `OpenMontage/.env.example`.
بعد إضافة مفتاح: `make preflight` للتأكد إنه انقرى.

> الأسعار ودعم اللغة العربية لكل مزوّد يتغير — تأكد من موقع المزوّد قبل الاشتراك.
