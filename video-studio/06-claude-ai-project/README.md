# استخدامه كمشروع في Claude.ai (Projects)

مجلد `video-studio` يشتغل مباشرة مع **Claude Code** (اللي ينفّذ الأداة فعلياً).
لو تبي كمان مشروع في **claude.ai** للتخطيط والسكربتات من الجوال/المتصفح:

1. في claude.ai ← **Projects** ← **Create project** ← سمّه «Video Studio».
2. انسخ محتوى `project-instructions.md` (اللي جنب هذا الملف) في **Project instructions**.
3. ارفع هذه الملفات في **Project knowledge**:
   - `01-brand/brand-kit.md`
   - `02-references/videos/video-references.md`
   - `02-references/designs/design-references.md`
   - `02-references/prompts/prompt-library.md`
   - `05-workflow/pipelines-cheatsheet.md`
   - `05-workflow/production-checklist.md`
   - `03-projects/_template/brief.md` و `script.md` و `shot-list.md`
4. لما تحدّث أي ملف هنا، ارفع النسخة الجديدة هناك (ما يتزامن تلقائياً).

> مشروع claude.ai ما يقدر يشغّل OpenMontage ولا يولّد فيديو — الإنتاج يصير في Claude Code.
