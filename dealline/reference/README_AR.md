# تسليم ديل لاين إلى Claude

## اقرأ هذا أولًا
هذه حزمة الملفات المتاحة من النسخة المبنية للموقع، وليست المصدر الأصلي الكامل.
تم التحقق من وجود اسم ديل لاين ونص «بيتك الجاي» في JavaScript المبني، بما يتوافق مع الصورة المرجعية. لم يتم التحقق من أنها آخر نسخة منشورة حاليًا.

## المحتويات
- build/dist/client: ملفات المتصفح المبنية، CSS والصور والخطوط.
- build/dist/server: ناتج بناء خادم Vinext وملفات إعداد التشغيل.
- build/dist/.openai: إعداد هوية الاستضافة الموجود في الأرشيف؛ لا تستخدمه للنشر إلى الموقع الحالي دون قصد صريح.
- project-context: وثائق المشروع الخمس عشرة كما وردت، دون تعديل.
- reference-screenshot.png: الصورة التي أرسلتها.
- CLAUDE_HANDOFF.md: تعليمات بدء العمل.
- FILES_SHA256.json: بصمات الملفات للمراجعة.

## ما هو غير متاح
ملفات src/app/components الأصلية، package.json، ملف قفل الاعتمادات، تاريخ Git وملفات الاختبار الأصلية غير موجودة في الأرشيف المتاح. لا توجد بيانات المتصفح الشخصية ضمن هذه الحزمة. لا تفترض وجود Backend أو دخول أو دفع فعلي لمجرد ظهور واجهته.

## التشغيل والتحديث
لا توجد أوامر npm install / npm run dev مؤكدة لهذه الحزمة؛ لا يوجد package.json. ناتج الخادم مرتبط بـ Vinext/Workers ولا يصح تقديمه كموقع HTML ثابت أو تشغيله بأمر node مفترض.
الأفضل تزويد Claude بمستودع المصدر الأصلي إن توفر. وإلا يراجع الحزمة ويعيد إنشاء مشروع قابل للصيانة مع الحفاظ على التصميم والسلوك المتحقق منه، ثم يضيف التحديثات ويختبرها. تعديل الحزم المجمعة مباشرة يصلح لترقيع محدود فقط.

الاسم الحالي المعتمد في الواجهة: ديل لاين. أسماء Hesba In في الوثائق هي أسماء تاريخية للمشروع؛ لا تغيّر القرارات المؤكدة بسبب تغيير الاسم.
